# 上下文压缩与裁剪 - 需求规格 (spec.md)

## 1. 背景

Agent 的 ReAct 循环会持续向上下文追加消息：LLM 响应、工具结果、用户消息。长任务中工具结果（文件内容、命令输出）动辄数千 token，当前 ContextManager 没有任何裁剪机制，上下文必然撑爆模型窗口，导致请求失败。

本需求为上下文管理引入**两层压缩机制**：入口截断（无 LLM）+ 摘要压缩（Agent 编排）。

---

## 2. 目标

- 超长工具结果在写入上下文时自动截断，杜绝单条消息失控
- 上下文逼近窗口上限时自动触发摘要压缩，长任务可以持续运行不中断
- 压缩过程保证 Function Calling 协议完整性（不拆散消息对）
- 压缩行为对工具实现、LLM Provider 完全透明

---

## 3. 详细需求

### 3.1 R1 - Token 估算修复

**功能描述**：替换现有单一 `/3` 字符估算，改为中英分桶估算。

**规则**：
- `tokens ≈ CJK字符数 / 1.5 + 非CJK字符数 / 4`
- 统计范围与现有实现一致：content + toolCalls 的 name/arguments

**理由**：现有 `/3` 对中文内容低估 token 数（中文实际 1 token ≈ 1.5 字），会导致裁剪不及时。

---

### 3.2 R2 - 工具结果入口截断

**功能描述**：`addMessage()` 写入 `role='tool'` 消息时，超长内容自动截断。

**参数**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 截断上限 | 4000 字符 | 可通过构造函数配置 |
| 保留策略 | 头 2/3 + 尾 1/3 | 中间插入 `...[已截断 N 字符]...` |

**约束**：
- 仅对 `role='tool'` 消息生效，user/assistant/system 不截断
- 未超限的消息原样保留
- 对 ContextManager 使用方完全透明（无需调用额外方法）

---

### 3.3 R3 - 压缩触发

**功能描述**：上下文 token 超过阈值时判定需要压缩。

**规则**：
- 触发条件：`getTokenCount() > maxTokens × 0.8`
- 检查时机：`Agent.run()` 每轮循环开头（callLLM 之前）
- ContextManager 只提供 `shouldCompact()` 判断，不自行发起压缩（无 LLM 访问能力）

---

### 3.4 R4 - 摘要生成（Agent 编排）

**功能描述**：Agent 将摘要区消息交给 LLM 压缩为结构化摘要。

**摘要提示词必须覆盖**：
1. 用户目标
2. 已完成的工作及结果
3. 关键文件与代码位置
4. 重要决策与约束
5. 待办事项

**约束**：
- 保留具体路径、命令、报错信息等可复用细节
- 摘要输出限长 ≤ 800 token
- 摘要请求不携带 tools 定义（纯文本压缩，避免 LLM 再次调用工具）
- 压缩过程中若用户 abort，本轮不应用压缩，下轮重新判断

---

### 3.5 R5 - 压缩应用与切点安全

**功能描述**：`compact(summary)` 将摘要区替换为一条摘要消息。

**分区规则**：
- 保留：system 消息 + 尾部最近轮次（按 token 预算 maxTokens × 25% 从尾部向前确定切点）
- 替换：system 之后到切点之前的所有消息 → 一条 `role='user'` 摘要消息，content 前缀 `[历史摘要]`

**切点安全（硬约束）**：
- 切点不得落在 `role='tool'` 消息上
- 若按预算算出的切点是 tool 消息，必须前移到其对应的 assistant 消息
- **不得拆散 assistant(toolCalls) ↔ tool 消息对**，否则 OpenAI 兼容协议报错

**防抖**：
- 压缩后 token 应降至 maxTokens × 50% 以下
- 若压缩后仍 ≥ 触发阈值（摘要超长等极端情况），跳过应用，避免反复压缩

---

### 3.6 R6 - 压缩事件

**功能描述**：压缩完成后通知 UI。

**事件**：`context_compact`
**data**：`{ before: number, after: number }`（压缩前后 token 数）
**时机**：compact 应用成功后、继续 ReAct 循环前

---

## 4. 配置

| 配置项 | 位置 | 默认值 |
|--------|------|--------|
| contextTokens | AgentConfig（可选） | 8000 |
| 截断上限 | ContextManager 构造参数 | 4000 字符 |
| 触发阈值 | ContextManager 内部常量 | 0.8 |
| 尾部保留预算 | ContextManager 内部常量 | 0.25 |

---

## 5. 安全与边界

- system 消息在任何情况下不得被裁剪或摘要
- `clear()` 行为保持不变（清空后由 Agent 重写 system prompt）
- 摘要消息本身超长的极端情况：跳过应用（见 3.5 防抖），不抛错

---

## 6. 非目标（本期不做）

- tiktoken 精确计数
- 跨会话持久记忆 / 向量检索 / 分级记忆
- 服务端 compaction
- 用户消息超长截断
- 压缩前快照/回滚（压缩是不可逆操作，v1 接受）
