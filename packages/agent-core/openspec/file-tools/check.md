# 文件操作工具集 - 验收清单 (check.md)

## 1. 安全验收

### 路径穿越防护
- [ ] 普通相对路径能正确解析
- [ ] `../` 开头的路径被拦截
- [ ] 中间包含 `../` 的路径被拦截
- [ ] 符号链接指向项目外被拦截
- [ ] 绝对路径（`/etc/passwd`）被拦截
- [ ] `.git` 目录被禁止访问

### 操作分级
- [ ] 只读工具（list_dir / read_file / search）：`requiresConfirmation = false`
- [ ] 写入工具（write_file / edit_file）：`requiresConfirmation = true`

---

## 2. list_dir 工具验收

### 基本功能
- [ ] 不传参数时列出项目根目录
- [ ] 指定子目录时列出对应目录
- [ ] `max_depth=1` 只列一层
- [ ] `max_depth=2` 列出两层
- [ ] 空目录有明确标识

### .gitignore 支持
- [ ] `node_modules` 目录被过滤
- [ ] `.gitignore` 中指定的文件被过滤
- [ ] 没有 `.gitignore` 文件时正常工作

### 错误处理
- [ ] 目录不存在时返回明确错误
- [ ] 路径是文件而非目录时返回明确错误
- [ ] 超出最大深度限制时返回错误

---

## 3. read_file 工具验收

### 基本功能
- [ ] 能正确读取文本文件内容
- [ ] 内容带行号，从 1 开始
- [ ] `offset` 参数生效（从指定行开始读）
- [ ] `limit` 参数生效（只读指定行数）
- [ ] offset 超出文件末尾时返回空或提示

### 边界情况
- [ ] 读取空文件正常
- [ ] 读取只有一行的文件正常
- [ ] 大文件（>100KB）超限返回明确提示，建议分段
- [ ] 二进制文件返回错误提示（不输出乱码）

### 错误处理
- [ ] 文件不存在时返回明确错误
- [ ] 路径是目录而非文件时返回明确错误
- [ ] 没有读取权限时返回明确错误

---

## 4. search_by_regex 工具验收

### 基本功能
- [ ] 简单字符串搜索能返回正确结果
- [ ] 正则表达式搜索能返回正确结果
- [ ] 每条结果包含：文件路径、行号、匹配行内容
- [ ] `max_results` 参数生效，结果不超过上限
- [ ] 结果超出 max_results 时有截断提示

### .gitignore 支持
- [ ] 不搜索 `node_modules` 中的文件
- [ ] 不搜索 `.gitignore` 中排除的文件

### 错误处理
- [ ] 无效的正则表达式返回明确错误
- [ ] 搜索路径不存在返回明确错误
- [ ] 没有匹配结果时返回明确提示（不是空字符串）

---

## 5. write_file 工具验收

### 基本功能
- [ ] 能创建新文件并写入内容
- [ ] 能覆盖已有文件
- [ ] 父目录不存在时自动创建
- [ ] 写入内容完全一致（无丢失、无乱码）

### 确认机制
- [ ] `requiresConfirmation = true`
- [ ] 未确认时不执行写入

### 错误处理
- [ ] 路径穿越被拦截
- [ ] 没有写入权限时返回明确错误
- [ ] content 为空时也能正常写入（创建空文件）

---

## 6. edit_file 工具验收

### 基本功能
- [ ] 单处匹配：正确替换 old_string 为 new_string
- [ ] 多处匹配 + replace_all=true：所有匹配都被替换
- [ ] 文件其他内容保持不变

### 错误场景
- [ ] old_string 完全不匹配：返回"未找到匹配"错误
- [ ] 多处匹配 + replace_all=false：返回"多处匹配不明确"错误
- [ ] 文件不存在：返回明确错误
- [ ] old_string 为空：返回参数错误

### 确认机制
- [ ] `requiresConfirmation = true`
- [ ] 未确认时不执行编辑

---

## 7. Agent 集成验收

### 工具注册
- [ ] Agent 启动后能列出所有 5 个文件工具
- [ ] 每个工具的 schema 正确（name / description / parameters）

### 端到端验证
- [ ] Agent 能主动调用 list_dir 探索项目
- [ ] Agent 能根据目录结构调用 read_file 读取具体文件
- [ ] Agent 能用 search_by_regex 定位代码
- [ ] Agent 能调用 write_file 创建新文件（需用户确认）
- [ ] Agent 能调用 edit_file 修改已有文件（需用户确认）
- [ ] 工具执行结果正确回灌给 LLM，Agent 能基于结果继续思考

---

## 8. 代码质量验收

- [ ] 所有文件工具都有清晰的注释
- [ ] 错误信息明确，Agent 能看懂并修正
- [ ] 代码遵循项目的目录结构和命名规范
- [ ] PathGuard 被所有文件工具正确使用（没有绕过）
- [ ] FsService 只接收已校验的绝对路径
